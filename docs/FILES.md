# File map

Every file in the repository (generated folders excluded) with what it does. Update this when files are added, renamed or removed.

## Root

| File | What it does |
|---|---|
| `CLAUDE.md` | Working agreement for Claude Code: project summary, hard rules (free tier, secrets, model id), conventions, commands, which doc to update when |
| `README.md` | Human setup guide: prerequisites, commands, owner checklist, links to docs |
| `AGENTS.md` | Generated by Astro: generic tips for AI agents working on Astro projects (keep; harmless) |
| `package.json` | Dependencies and npm scripts (`dev`, `build`, `preview`, `generate-types`) |
| `package-lock.json` | Exact dependency versions (commit it) |
| `astro.config.mjs` | Astro config: site URL, static-by-default output, Cloudflare adapter options, Tailwind Vite plugin, Preact, sitemap filter |
| `wrangler.jsonc` | Cloudflare Worker config: entry, static assets, D1/R2/KV/AI/Workflows bindings, cron trigger, non-secret vars |
| `worker-configuration.d.ts` | Generated by `npm run generate-types`: the `Env` type for all bindings and vars. Regenerate after editing `wrangler.jsonc` |
| `tsconfig.json` | TypeScript settings (Astro strict preset, Preact JSX, includes the generated types) |
| `.gitignore` | Excludes build output, `node_modules`, `.wrangler`, secrets (`.dev.vars`, `.env`) |
| `.dev.vars.example` | Template listing every secret needed in later phases; copy to `.dev.vars` (never committed) |
| `.claude/launch.json` | Lets the Claude desktop app start `npm run preview` or `npm run dev` on port 4321 |
| `.vscode/extensions.json`, `.vscode/launch.json` | Generated by the Astro template: recommends the Astro VS Code extension and a debug launch config |

## `src/`

| File | What it does |
|---|---|
| `src/worker.ts` | Worker entry: `fetch` delegates to Astro; `scheduled` handles the hourly cron; exports the `ModeratePost` Workflow class (stub in Phase 0) |
| `src/env.d.ts` | Tells TypeScript that `Astro.locals.runtime.env` has the `Env` bindings |
| `src/lib/site.ts` | Site constants: name, tagline, description, author, locale. Change here, applies everywhere |
| `src/layouts/BaseLayout.astro` | The single `<head>` owner: title template, description, robots, icons, theme colour. Phase 1 adds canonical, Open Graph, JSON-LD, AdSense meta and consent |
| `src/pages/index.astro` | Home page (static). Phase 0 placeholder built on the design tokens |
| `src/pages/api/health.ts` | `GET /api/health` (on-demand): checks D1, KV, R2, AI and Workflow bindings; returns JSON with `ok` and per-service status |
| `src/styles/global.css` | Tailwind v4 entry, Typography plugin, design tokens under `@theme`, base styles, `prose-article` utility |

Planned folders (created in later phases): `src/components/` (static UI), `src/islands/` (Preact: Editor, RaiseButton, CommentForm, ReportButton), `src/content/` (editorial Markdown), `src/lib/db/` (Drizzle schema), `src/lib/moderation/` (pipeline steps), `src/workflows/` (full Workflow), `src/cron/` (hourly jobs), `drizzle/` (migrations), `tests/`.
